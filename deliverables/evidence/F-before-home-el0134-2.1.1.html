Case for a failure

The element's navigation functionality is blocked from keyboard users by design. The anchor contains `onfocus="blur();"` which immediately removes focus when a keyboard user tabs to it, preventing activation via keyboard. This is a direct, intentional barrier to keyboard operation of the home navigation link.
Quoted: "onfocus="blur();""; "onmouseover="switchImage('nav_home', './img/nav_home2.gif'); ChangeColor('home','#FFF')""; "Ensure the functionality provided by mousing over this element is available through the keyboard"
Strength: 5/5

Case against a failure

The onmouseover and onmouseout handlers only change visual styling (image swap and background color). These are purely decorative hover effects; the actual navigation functionality is delivered by the anchor element's href. However, the anchor uses onfocus='blur()' which programmatically removes focus, making the link itself inoperable by keyboard. This destroys keyboard access to the navigation function entirely. No honest pass case exists.
Quoted: "onfocus="blur();""; "href="javascript:location.href='home.html';""
Strength: 1/5

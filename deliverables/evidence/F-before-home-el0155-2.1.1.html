Case for a failure

The element uses only mouse-specific events for its interactive functionality. The anchor contains 'onfocus="blur();"' which immediately removes focus when a keyboard user tabs to it, making the link inoperable via keyboard. This programmatically prevents keyboard access to the survey navigation link, a clear failure of 2.1.1.
Quoted: "onfocus="blur();""; "onmouseover="switchImage('nav_survey', './img/nav_survey2.gif'); ChangeColor('survey','#FFF')""; "onmouseout="switchImage('nav_survey', './img/nav_survey.gif'); ChangeColor('survey','#EDEDED')""
Strength: 5/5

Case against a failure

No honest case exists. The element contains `onfocus="blur();"` which programmatically removes keyboard focus the moment the link receives it, making the navigation link completely inoperable via keyboard. The underlying function — navigating to survey.html — does not require path-dependent input, so no exception applies. The scanner confirms mouse-only functionality with no keyboard equivalent provided.
Quoted: "onfocus="blur();""; "javascript:location.href='survey.html';"; "Ensure the functionality provided by mousing over this element is available through the keyboard"

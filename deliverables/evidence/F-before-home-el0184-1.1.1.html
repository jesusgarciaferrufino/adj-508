Case for a failure

The element presents an image via CSS background-image with no text alternative. The HTML contains only a generic title='image' and an empty inner div. The scanner confirms the image's information is inaccessible to screen readers. Under 1.1.1, non-text content requires a text alternative serving equivalent purpose.

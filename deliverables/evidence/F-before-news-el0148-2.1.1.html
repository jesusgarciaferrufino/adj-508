Case for a failure

The element uses `onmouseover` and `onmouseout` exclusively for its interactive visual feedback. The anchor inside contains `onfocus="blur();"`, which programmatically removes focus the instant a keyboard user tabs to it, making the link completely inoperable via keyboard. This actively destroys keyboard access rather than merely omitting it.
Quoted: "onfocus="blur();""; "onmouseover="switchImage('nav_facts', './img/nav_facts2.gif'); ChangeColor('tickets','#FFF')""; "onmouseout="switchImage('nav_facts', './img/nav_facts.gif'); ChangeColor('tickets','#EDEDED')""; "Ensure the functionality provided by mousing over this element is available through the keyboard"
Strength: 5/5

Case against a failure

The onmouseover/onmouseout handlers only change visual styling (image swap and background color). These are purely decorative hover effects; the actual navigation functionality is delivered by the anchor element linking to tickets.html. The core functionality — navigating to that page — is operable via keyboard through the anchor. However, the anchor uses onfocus='blur()' which programmatically removes focus, making the link unreachable by keyboard. No honest pass case exists.
Quoted: "onfocus="blur();""; "href="javascript:location.href='tickets.html';""
Strength: 1/5
